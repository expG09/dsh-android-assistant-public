# DSH 砚砚助手 · 安卓语音端

把你的手机变成 DeepSeek Harness 的**远程话筒和喇叭**：手机上按住说话 → 电脑上的 DSH 收到文字并回复 → 回复在手机上念出来。

这套东西分两块，装在一起才算通：

```
phone-bridge/        DSH 插件（内含 channel-server），装在电脑上
  └ channel-server/  手机连进来的服务端（WebSocket 8788）
app/                 安卓 App，装在手机上
```

> 个人自用项目，不是产品。代码够用就行，没做工程化打磨（没有 CI、没有单元测试套件、release 包要自己签）。

## 它怎么工作

```
手机 App ──WebSocket(8788)──> channel-server ──HTTP(127.0.0.1:8795)──> phone-bridge 插件
                                                                          │
                                                                    DSH 会话（你指定的那个）
                                                                          │
手机 App <──────── 回复正文（手机端自转语音）────────────────────────────┘
```

语音识别和语音合成都发生在**手机上**：手机把你说的话转成文字发过来，电脑只收文字、只回文字。所以电脑不需要麦克风和音箱。

## 前置

- **DeepSeek Harness 桌面端**（插件要装在里面）
- **Node.js**（channel-server 需要；`ws` 已随包自带，不用 npm install）
- **安卓手机**（Android 8.0 / API 26 以上）
- **Tailscale**（推荐）：手机和电脑各装一个、登同一账号，手机就能用电脑的 `100.x` 地址连过来，不用管路由器和公网 IP

不用 Tailscale 也行，但那就得在同一个局域网里，并且自己保证端口可达。

## 装电脑那一半

1. DSH → 插件 → 添加插件 → 选本地目录 → 选这个仓库的 `phone-bridge/`
2. 重启桌面端
3. 打开 设置 → 左侧「语音通道」：
   - **投递会话**：填一个 DSH 会话 id 并点「绑定」。不绑的话手机消息一律被拒（409），这是有意的——宁可拒绝，不猜。
   - 点「启动」：channel-server 起来，监听 8788
   - 记下那行「电脑端地址」，形如 `ws://100.x.x.x:8788`
4. 首次启动会自动生成 `PHONE_BRIDGE_TOKEN` 写进 `phone-bridge/channel-server/.env`；想用语音合成就在面板里填 DeepSeek API key（只存在那个 `.env` 里，面板只回掩码）

## 装手机那一半

1. 从 Releases 下 APK（或自己 `./gradlew assembleDebug` 编一个）
2. 打开 App → 设置 → 通道与配对 → 填电脑端地址 `ws://100.x.x.x:8788`
3. 面板上点「生成配对码」，把 6 位码填进 App → 配对
4. 配对码 5 分钟有效、用一次就失效

## 连不上时按这个顺序查

1. **8788 有没有在听**：`netstat -ano | findstr :8788`（电脑重启后插件没自动起来的话，面板点一次「启动」）
2. **Tailscale 通不通**：手机上能不能打开 `http://100.x.x.x:8788/healthz`
3. **地址对不对**：App 里填的必须是 `ws://…:8788`，别填成 8795——8795 是插件自己的回环端口，手机连不上
4. **有没有绑定会话**：面板显示「未绑定」时手机发消息会被拒
5. **配对过期**：6 位码 5 分钟就废，重新生成一个

## 已知限制

- **TTS 只实现了 DeepSeek 一家**。面板上的 Edge / 本地是配置占位，选了不改变实际播报。
- **录屏时录音不可用**：Android 10 起麦克风独占，录屏应用占着就轮不到我们，会明确提示。
- **离线设备没有「最近活跃」时间**：事件日志里没存设备标识，只有在线设备能显示时间。
- **debug 包偏大**（约 37 MB）：里面带了离线关键词唤醒模型和 sherpa-onnx 的 AAR。

## 隐私说明

- 密钥只落在电脑本地的 `.env` 文件里，不进仓库、不上传；面板里只显示掩码。
- channel-server 监听 `0.0.0.0:8788` 是为了让手机经 Tailscale 连进来；`/admin/*` 管理接口只接受**本机回环**请求，非回环一律 404。
- 配对凭据存在 `data/devices.json`，只存设备标识的 SHA-256。
- 这个项目本身不收集、不上传任何数据；你的语音识别在手机上完成，文字走你自己的 DSH。

## 目录

```
app/                                   安卓 App（Kotlin）
phone-bridge/                          DSH 插件。安装时选这个目录
  ├─ index.js / client.js / lib/       投递 + 设置面板
  ├─ selfcheck.mjs                     本地预检（不装插件也能跑：node selfcheck.mjs）
  └─ channel-server/                   手机连进来的服务端（含 vendor 的 ws）
gradle/ gradlew gradlew.bat            构建脚本
```
